##Shop Reporter

#About

Shop Reporter is an application developed to support marketplace data analysis and reporting.

#API Integration

The application is intended to integrate with the Allegro API using OAuth 2.0 authorization.

All API interactions will comply with Allegro Developer Program requirements.

Official documentation: https://developer.allegro.pl/

#Repository Purpose

This repository provides general information about the application for the Allegro API registration process.

No source code, credentials, API keys or access tokens are stored in this repository.
